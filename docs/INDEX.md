## 🎯 Fluxos Recomendados

### Fluxo 1: Primeiro Teste (15 minutos)
1. Leia [INICIO_RAPIDO.md](../INICIO_RAPIDO.md)
2. Execute teste no Test Explorer
3. Veja [tests/examples/test_exemplo_basico.py](../tests/examples/test_exemplo_basico.py)

### Fluxo 2: Aprender Playwright (1 hora)
1. Leia [tests/examples/GUIA_RAPIDO.md](../tests/examples/GUIA_RAPIDO.md)
2. Execute exemplos em [tests/examples/](../tests/examples/)
3. Crie seu primeiro teste

### Fluxo 3: Testes Profissionais (2 horas)
1. Leia [core/ui/base_page.py](../core/ui/base_page.py)
2. Veja [tests/examples/test_wikipedia.py](../tests/examples/test_wikipedia.py)
3. Crie Page Objects para sua aplicação

### Fluxo 4: Integração Completa (3 horas)
1. Leia [core/database/README.md](../core/database/README.md)
2. Veja [tests/frontend/test_ui_backend_db_integration.py](../tests/frontend/test_ui_backend_db_integration.py)
3. Implemente testes end-to-end
